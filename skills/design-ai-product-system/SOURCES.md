# Sources and Boundaries

This skill synthesizes production AI-product principles rather than reproducing source text.

## Conceptual sources

- Chip Huyen, *AI Engineering: Building Applications with Foundation Models* — use-case fit, evaluation, architecture, agents, feedback, monitoring, and operations.
- Itamar Gilad, *Evidence-Guided* — evidence-calibrated confidence and proportional investment.
- Jeff Gothelf and Josh Seiden, *Lean UX* — outcomes, hypotheses, learning loops, and cross-functional work.

## Repository boundaries

- `design-human-ai-interactions` owns interaction transparency, uncertainty, control, and recovery depth.
- `product-review` owns full product/business audit and final global priority.
- `product-experiment` owns evidence method when assumption testing is primary.
- `product-metrics` owns the broader product measurement system.
- This skill owns the integrated AI product, architecture, evaluation, feedback, guardrail, operations, and staged-release contract.

Model capability, price, provider policy, privacy/security guidance, and law change. Verify material current claims from primary sources. This skill is not legal, security, accessibility, or domain-safety certification.
