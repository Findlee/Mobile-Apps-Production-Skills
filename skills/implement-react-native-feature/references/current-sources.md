# Current React Native Source Routing

Use books for mental models and official documentation for current commands, APIs, supported versions, and architecture.

Inspect the installed dependency graph first, then consult only relevant sources:

- React Native guides: https://reactnative.dev/docs/getting-started
- React Native architecture: https://reactnative.dev/architecture/landing-page
- React Native testing: https://reactnative.dev/docs/testing-overview
- React Native performance: https://reactnative.dev/docs/performance
- React Native native platform: https://reactnative.dev/docs/native-platform
- React Native security: https://reactnative.dev/docs/security
- React rules: https://react.dev/reference/rules
- React learning guides: https://react.dev/learn
- React Compiler: https://react.dev/learn/react-compiler
- TypeScript handbook: https://www.typescriptlang.org/docs/handbook/intro.html
- TypeScript configuration: https://www.typescriptlang.org/tsconfig/

If the repository uses Expo, also inspect its SDK version and use https://docs.expo.dev/ for development builds, Router, modules, updates, and EAS. Do not impose Expo on a bare project or eject a managed project without an explicit need.

For third-party libraries, use documentation matching the locked version. Check React Native New Architecture compatibility and native installation requirements before editing code.
