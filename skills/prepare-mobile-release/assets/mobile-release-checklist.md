# Mobile Release Checklist

## Identity

- [ ] Reviewed commit and branch
- [ ] App or bundle IDs
- [ ] Version and build numbers
- [ ] Channel, environment, and store targets
- [ ] Minimum OS and supported devices

## Build and credentials

- [ ] Clean automated build
- [ ] Locked dependencies and recorded toolchain
- [ ] Protected signing and provisioning
- [ ] Correct flavor, scheme, profile, assets, and endpoints
- [ ] Symbols, source maps, mappings, hashes, and provenance archived

## Compatibility and policy

- [ ] Server supports old and new clients
- [ ] Local schema and queued work migrate safely
- [ ] Permissions, entitlements, deep links, push, and native SDKs reviewed
- [ ] Privacy, data safety, account, purchase, and review declarations current
- [ ] OTA/native-runtime compatibility confirmed when applicable

## Verification

- [ ] Static checks and automated tests
- [ ] Signed candidate installed
- [ ] Critical journeys and failure recovery
- [ ] Clean install and supported upgrades
- [ ] Offline, background, and account switching
- [ ] Android and iOS device coverage
- [ ] Release performance and accessibility
- [ ] Diagnostics symbolication verified

## Rollout and recovery

- [ ] Stages, owner, observation window, and halt criteria
- [ ] Version-segmented dashboards and alerts
- [ ] Remote disable or server compatibility action
- [ ] Hotfix and OTA rollback boundaries
- [ ] Support and incident communication readiness
