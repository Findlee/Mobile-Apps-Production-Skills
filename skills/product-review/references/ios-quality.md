# Apple Platform Product-Quality Reference

Reviewed: 2026-08-08
Source type: dynamic official guidance

Re-check current Apple documentation for release-critical requirements.

## Stable product-review themes

Apple Human Interface Guidelines emphasize designing experiences that feel appropriate to the platform and are grounded in user purpose.

Current design principles include:

- purpose;
- consistency and established patterns;
- flexibility/inclusion;
- simplicity;
- craft;
- delight.

Use these as decision principles, not a visual style checklist.

## Platform review prompts

Check:

- Does the app feel familiar enough to Apple-platform users?
- Are system conventions preserved unless deviation has a product reason?
- Does the design adapt to supported configurations?
- Are content and controls logically organized?
- Are unnecessary elements removed?
- Is accessibility treated as a core quality dimension?
- Are multiple input methods supported where the platform/use case requires them?
- Is user context preserved across transitions/configurations?

## Accessibility prompts

Where relevant test/review:

- VoiceOver labels and ordering;
- visible changes announced appropriately;
- Larger Text / Dynamic Type behavior;
- sufficient contrast;
- color not used as the only signal;
- Reduce Motion;
- Voice Control;
- captions/audio descriptions for media;
- dark appearance;
- custom controls remaining accessible.

## Layout/platform adaptation

Check relevant platform behavior:

- safe areas;
- orientation;
- iPad multitasking/resizing if supported;
- Dynamic Type;
- system appearance changes;
- standard controls/gestures;
- context preservation.
